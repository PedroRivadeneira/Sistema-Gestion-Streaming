# Mapeo de requisitos del proyecto final

| Requisito | Evidencia en el proyecto |
|---|---|
| Proyecto completo en GitHub | Código fuente, documentación y pruebas en el repositorio |
| README | `README.md` con autor, fecha, objetivo y funcionalidades |
| Aplicación web | API REST implementada con `net/http` |
| 8 servicios web | La API expone más de 8 rutas funcionales |
| JSON | Codificación y decodificación con `encoding/json` |
| Integración de las 4 unidades | Modelos, interfaces, errores, REST, JSON, concurrencia y testing |
| POO | Structs, métodos, encapsulación, composición e interfaces |
| Concurrencia | Goroutines, channel, `sync.WaitGroup` y `sync/atomic` |
| Pruebas unitarias | Archivos `_test.go` y paquete `testing` |
| Pruebas HTTP | `net/http/httptest` en `src/api/server_test.go` |
| Integración | `go test ./...` y pruebas del conjunto de paquetes |
| Aceptación | Demostración manual de la API y casos de uso definidos |
| Funcionalidad creativa | Búsqueda por múltiples filtros y estadísticas concurrentes |
| Visualización del futuro | `docs/vision-futura.md` |
| Diagrama de clases | `docs/diagrama-clases.md` |
