# Visualización del futuro

## Evolución propuesta

La visión futura del Sistema de Gestión de Streaming es convertir la API actual en una plataforma distribuida con una experiencia de usuario completa.

### 1. Aplicación web y móvil

El cliente consumiría la API REST actual desde una interfaz web y una aplicación móvil. Los mismos servicios permitirían registrar usuarios, consultar el catálogo, gestionar planes y revisar suscripciones.

### 2. Persistencia real

Los Maps y Slices utilizados en esta etapa podrían reemplazarse progresivamente por una base de datos para conservar la información entre reinicios y soportar un volumen mayor de usuarios y contenidos.

### 3. Recomendaciones

El sistema podría analizar el historial de consultas y contenidos para generar recomendaciones personalizadas. Esta sería una de las funcionalidades de mayor valor para el usuario.

### 4. Escalabilidad y concurrencia

La API podría distribuirse entre varios servicios y utilizar colas, caché y procesamiento concurrente para soportar un número mayor de solicitudes simultáneas.

### 5. Seguridad

En una evolución posterior se incorporarían autenticación, autorización por roles, HTTPS, gestión segura de credenciales y validación más completa de las entradas.
